## Interpretation / boundary

Evidence points to the return path (RX radio emission/air/TX reception) rather
than RX application stopping its own replies. LocalTXsuccess does not confirm
peer receipt; CRC windows do not authenticate a sender. Cannot yet distinguish
close-distance RF effects, interference, antenna/power/front-end hardware or
driver behavior, and cannot claim proven receiver saturation. Capture windows
are offset~0.34s and host timestamps include transport delay, not RF timestamps.
