## Design

ADR-019 and `docs/OTA_WIRE.md`: Host0x11 carries at most100 image bytes; TX sends
ten-byte RF fragments (operation7) locally with1000us post-TX guard, then requests
one operation8 block ACK. Receiver bitmap/cache validates all fragments before
one bounded storage write; missing fragments trigger whole-block retransmission.
Identical last-block retransmissions do not write twice; altered duplicates fail.
Partial fragments do not renew10s progress timeout. Legacy/fast data cannot mix.
CRC, fingerprint, MD5, full-speed maintenance and explicit Commit remain intact.
No changes to pins, PWM/Tach, power, C6 or compatibility fingerprint.

`--mode legacy` remains default: new TX can upgrade a running0.1.8 RX to this
candidate through its old10-byte OTA path. Use `--mode fast --rate3072` only after
both running endpoints have this extension. OldRX fast timeout is not successful
capability negotiation, and no automatic fallback mixes a partially active mode.
