## 已确认并修复的问题

| 问题 | 最终修复 |
| --- | --- |
| TX 将处理结束时间当作回包时间，误丢按时观察到的包 | 在 SPI 处理前记录 DIO 观察时间，按原始 5 ms 期限验证；保留最后不足 1 ms 的接收机会 |
| RX 读包、rearm 和 PWM 处理后再叠加完整 1.2 ms 等待 | 从观察时间抵扣已有耗时；调用发送前已过期的回复跳过 |
| 同步字错误可能结束单包接收，而软件仍认为接收已启用 | 在启动 RX 前显式映射 sync-error IRQ，消费错误后有界重新接收 |
| TX 遥测年龄的毫秒取整可能使数据变新 1 ms | 向旧取整；普通时钟、micros 与 millis 回绕均有 RED/GREEN 回归 |
| C6 共用日志限流会遮蔽诊断；分类限流仍会因抖动漏节点 | 35 个固定最新值槽，RFN/RFT 各覆盖 n1..16，类别和节点公平轮转；全局至少 200 ms 输出间隔，携带接收时间与缓存年龄 |

错误节点/序号/长度/CRC 拒收、满速保护、25 kHz PWM、射频参数以及 C6 的在线阈值和灯效均保留。DIO 时间是软件观察时间；RX 的 5 ms 检查限制发送函数调用前年龄，并不证明实际空口发送不会跨槽。
